2. Allgemeine Informationen

DaheimSmart ist derzeit ein persönliches Projekt und wird aktuell ohne eingetragene geschäftliche Tätigkeit betrieben. Die Website dient dazu, Informationen über Smart-Home-Technik, Energie, Sicherheit, Komfort und Kosten verständlich aufzubereiten.

3. Hosting über GitHub Pages

DaheimSmart wird über GitHub Pages veröffentlicht. Beim Aufruf der Website können durch die technische Infrastruktur des Hosting-Anbieters Informationen über den Zugriff verarbeitet werden. Diese Verarbeitung kann insbesondere der Bereitstellung, Sicherheit, Stabilität und dem Schutz der technischen Infrastruktur dienen. Für die Verarbeitung durch GitHub gelten zusätzlich die Datenschutzbestimmungen von GitHub.

4. Keine eigenen Benutzerkonten oder Newsletter

DaheimSmart bietet derzeit keine eigenen Benutzerkonten, Registrierungen, Newsletter oder Kundenkonten an.

Die Website enthält derzeit auch kein eigenes Kontaktformular.

5. Rechner und Vergleichswerkzeuge

DaheimSmart enthält interaktive Werkzeuge, beispielsweise einen Stromkosten-Rechner und einen Produktvergleich. Die dabei eingegebenen Werte werden aktuell direkt im Browser des Nutzers verarbeitet.

Nach dem derzeitigen technischen Stand werden diese Eingaben durch DaheimSmart nicht über einen eigenen Server gespeichert oder an einen eigenen Server übertragen.

Wenn du DaheimSmart per E-Mail kontaktierst, werden die von dir übermittelten Angaben und der Inhalt deiner Nachricht verarbeitet, soweit dies für die Bearbeitung deiner Anfrage erforderlich ist.
