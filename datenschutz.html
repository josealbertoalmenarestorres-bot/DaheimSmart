DaheimSmart wird über GitHub Pages veröffentlicht. GitHub stellt hierfür die technische Infrastruktur zur Verfügung.

DaheimSmart speichert diese Eingaben derzeit nicht auf einem eigenen Server und erstellt daraus kein persönliches Benutzerprofil.

Die übermittelten Daten werden nur so lange aufbewahrt, wie dies für die Bearbeitung der Anfrage erforderlich ist oder gesetzliche Aufbewahrungspflichten bestehen.
